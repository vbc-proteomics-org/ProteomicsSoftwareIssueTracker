# ProteomicsSoftwareIssueTracker — agent notes

`CONTRIBUTING.md` is the rulebook for every change here, by people and agents alike. Read it before
writing anything.

An agent skill for contributing here (`proteomics-issue-tracker`) is maintained outside this
repository. It contains process only and reads the rules from this repository at run time, so a rule
change belongs here — in `CONTRIBUTING.md`, the labels, the form or the templates — not in the skill.

This repository is public-facing: anything posted (issues, comments, labels, commits) is read by
vendors. Confirm with the user before posting.
