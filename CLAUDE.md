# ProteomicsSoftwareIssueTracker — agent notes

`CONTRIBUTING.md` is the rulebook for every change here, by people and agents alike. Read it before
writing anything.

The agent skill `skills/proteomics-issue-tracker/` deliberately contains process only and reads the
rules from this repository at run time. When a rule changes, change `CONTRIBUTING.md` (or the labels,
form or templates), not the skill. Change the skill only when it names a file or step that no longer
exists.

This repository is public-facing: anything posted (issues, comments, labels, commits) is read by
vendors. Confirm with the user before posting.
